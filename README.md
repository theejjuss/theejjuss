> **Problem** — After a landslide, quickly identifying which buildings are damaged is critical for prioritizing rescue efforts, but manual assessment from disaster imagery is slow.
>
> **Solution** — A computer vision pipeline that segments pre- and post-disaster imagery and classifies building damage into severity levels to support faster rescue prioritization.

```text
xView2 / RescueNet → Pre/Post Disaster Images → Preprocessing
     → U-Net Segmentation → Patch Extraction → CNN Classification
     → Damage Assessment
```

| Damage Classes | Technologies | Concepts |
